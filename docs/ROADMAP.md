# Следующие этапы

1. Создать приватный репозиторий, загрузить код, получить зелёную сборку Actions.
2. Проверить приложение на телефоне с работающим сервером HA.
3. Проверить недействительный токен, потерю сети, недоступное устройство, поворот экрана.
4. Добавить постоянную подпись APK, вход OAuth и обновление состояний через WebSocket.
5. Реализовать встроенное видео и список камер с безопасным хранением учётных данных.
6. Добавить управление климатом с пределами температуры из возможностей устройства.
7. Комнаты, избранное, сценарии «Дома», «Уехал», «Ночь» после определения реальных действий.
8. Проверить VPN с мобильной сети; локальную работу при отключении интернета.
9. Уведомления, архив Frigate и события камер; оценить нагрузку Raspberry Pi.

Критерий готовности первой рабочей версии: пользователь может подключить HA,
увидеть реальные состояния, управлять тестовой лампой и открыть камеру.
Макет из обсуждения является направлением дизайна, не подтверждением реализованных функций.
