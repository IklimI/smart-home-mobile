# Сервер дома

1. Уточнить модель Raspberry Pi, блок питания и накопитель.
2. Установить Home Assistant OS по официальной инструкции, подключить Ethernet.
3. Создать администратора сервера, отдельного пользователя для приложения.
4. Настроить резервные копии и сохранить одну копию вне Raspberry Pi.
5. Закрепить DHCP-адрес сервера и камер в роутере.
6. Добавить устройства Tuya/Smart Life. Локальную интеграцию выбирать только после проверки моделей.
7. Через «Настройки → Устройства и службы» добавить Generic Camera с рабочим RTSP-адресом.
   Учётные данные камеры вводить только в сервере/плеере, не в GitHub.
8. Проверить одну лампу, показания одного датчика и видео одной камеры.
9. Для VPN сначала определить модель роутера, возможности входящего соединения и CGNAT.
10. Frigate и архив устанавливать после выбора накопителя и проверки нагрузки.

Пример содержимого панели (заменить entity_id на реальные в Home Assistant):

```yaml
title: Мой дом
views:
  - title: Дом
    path: home
    cards:
      - type: entities
        title: Устройства
        entities:
          - light.example_yard
          - sensor.example_temperature
      - type: thermostat
        entity: climate.example_room
      - type: picture-entity
        entity: camera.example_gate
        camera_view: live
```

Этот YAML добавляется вручную в редактор панели, не заменяет configuration.yaml.
До замены примерных entity_id карточки не работают.
